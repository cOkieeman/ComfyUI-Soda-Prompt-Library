## 0.1.2 完整使用流程排查（2026-11-01）

本轮先运行原有测试，再通过可控延迟和异常数据复现边界问题。确认并修复：

- 异步选择：移除素材后迟到的详情请求会恢复该项；改变筛选后旧随机响应仍会加入组合。现在切换查询或移除当前类型时使旧请求失效，输入搜索词时立即生效；同时检查随机期间改选卡片后按钮能继续使用。
- 列表错误：查询失败会保留旧页卡片及可用分页按钮。现在加载时清空旧页并禁用分页，失败时显示错误，恢复请求后可继续浏览。刷新失败也不会永久显示“正在读取”。
- 复制回退：剪贴板权限被拒绝时，原文仍折叠，无法直接使用备用复制方式。现在展开、聚焦并选中原文。
- Neons 异常隔离：图片索引类型错误会抛出 AttributeError，损坏的预览记录或 family 字段也会阻止后续有效条目加载。现在预览错误只产生提示，文字保留；无效条目跳过后继续读取。

验证结果：Python unittest 17 项、Node.js 4 项、浏览器行为回归 13 项全部通过；Ruff 检查、格式检查和 JavaScript 语法检查通过。浏览器回归包含组合顺序、原文保留、替换确认、快照 JSON 往返、来源删除、异步乱序、复制权限拒绝、展开预览及失败恢复。测试只使用通用临时数据。

实际 ComfyUI 页面检查：60 张卡片高度完整、609 页分页可切换、空搜索清空列表、数据源筛选正确、服饰与内容选择保持分离、随机内容可预览、取消替换后原正文不变；512×768 原图正常加载。插件相关浏览器错误日志未见新增错误。磁盘 Anima 工作流的库节点仍连到 ImpactWildcardEncode.populated_text，模式为 fixed。

当前本机 API 返回角色 36,510 条、服饰 432 条、内容 2 条示例，无来源警告。三次缓存列表请求分别约 29–53ms、1.5–2ms、0.9–1ms；仅代表当时本机状态。
