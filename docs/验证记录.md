# 0.1.0 验证记录

## 0.1.1 预览布局修复

复现了满页 60 条时 CSS Grid 自动行高被压缩的问题：卡片只有约 17px 高，内部内容约 201px 被裁切。改为按内容确定行高，整页列表滚动；合并预览改为完整换行文字，操作栏与滚动区域分离，并增加展开预览和复制全文。

通用回归页面验证：60 张卡片均不裁切、列表可滚动，2270 字符正文完整显示且复制长度一致，展开视图可滚动到最后一段，Escape 返回主面板。720px 窄窗口下卡片完整、操作栏不覆盖内容。该页不加载个人素材。

日期：2026-11-01。环境：Windows、ComfyUI 0.42.0（8baf68d5），独立 CPU 测试服务。

## 自动化检查

- Python unittest：15 项，通过。覆盖 JSON / Aaalice / Neons 读取、精确保留文本、分页、随机、更新与删除、无效配置、预览路径边界及 HTTP 响应。
- Node.js：4 项，通过。覆盖组合顺序、快照隔离、JSON 保存恢复和 ComfyUI 响应式属性包装。
- Ruff lint 和 format 检查通过。

1200 条通用内容记录的测试验证了索引、每页 60 条以及列表响应不附带完整正文。另在本机约 3.7 万条实际只读素材上测量：首次构建索引约 6.8 秒，缓存后 10 次搜索平均约 23 毫秒。结果受磁盘和机器性能影响；不是跨环境性能承诺。

## 浏览器与 ComfyUI

- 在三个页签中选择通用示例，确认角色 → 服饰 → 内容的原文与空行组合。
- 载入正文后手改，保存独立工作流，在新页面打开，手改文字和组合快照均恢复。
- 实际发现并修复了重新打开时 reactive Proxy 无法 structuredClone 的问题。
- 从本地现有素材库读取缩略图，打开 512×768 预览图，确认图像加载完成。
- 复制条目文字到剪贴板，载入时出现替换提示；取消后手改文字保持不变。
- 导出 API 图，确认输入是手改后的正文。
- 将导出的文本节点连接到内置 PreviewAny，在独立 CPU 服务执行成功，预览输出与手改正文一致。

## Anima 试点

在本地独立工作流副本中添加一个节点，连接 ImpactWildcardEncode.populated_text，设置 fixed；原有连线和子图定义保持不变。对节点、连线引用和原文件未变更进行了静态校验。

该完整工作流依赖用户原有插件与模型，未在仅加载本插件的隔离环境中执行完整流程。没有启动 GPU 图像生成，也没有验证成图质量或多人服装绑定。个人工作流和预览图库不随公共仓库发布。
