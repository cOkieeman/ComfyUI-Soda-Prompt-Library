# 数据格式与接入

## 推荐交付目录

```text
my-library/
├── characters/              # 可选：角色 JSON
├── outfits/                 # 可选：服饰 JSON
├── content/                 # 按族分文件的内容 JSON
│   └── daily_garden.json
└── previews/
    └── garden_001.webp
```

节点扫描每个配置目录直接包含的 `*.json`，不递归。500–1200 条可以放在多个文件内，后续继续增加文件或 entries 即可。库只读，更新后在面板点击“刷新库”，或者稍后重新搜索；浏览请求的自动变更检查间隔为 2 秒。

## 完整文本格式

```json
{
  "schema": 1,
  "family": "daily/garden",
  "label": "日常 · 庭院",
  "entries": [
    {
      "id": "garden_001",
      "title": "庭院浇花",
      "text": "one adult person, solo, watering flowers, garden, morning light",
      "scene": "garden",
      "camera": "eye-level",
      "focal": 50,
      "preview": "garden_001.webp",
      "ver": 1
    }
  ]
}
```

| 字段 | 要求 / 用途 |
| --- | --- |
| `schema` | 必填整数，当前为 `1` |
| `family` | 必填字符串，建议小写字母、数字、下划线和 `/`；用于族筛选 |
| `label` | 必填字符串，显示分类名称 |
| `entries` | 必填数组 |
| `id` | 必填，`[a-z0-9_]+`；同一数据源跨文件唯一，修改时保持稳定 |
| `title` | 可选显示名称；未提供时显示 ID。建议填写中文便于搜索 |
| `text` | 推荐提供完整正文，字符串中的空白、换行、重复词均原样保留 |
| `preview` | 相对图片目录的文件名 / 子路径，或 `null`；推荐 `{id}.webp` |
| `ver` | 建议从 `1` 开始的修订号，改词或换图后递增 |
| `scene` / `camera` | 可选字符串筛选字段 |
| `focal` / `intensity` | 可选数值筛选字段 |
| `undress` | 可选字符串筛选字段，不驱动服装自动裁剪 |

图片建议宽度 512px。支持 `.png` / `.jpg` / `.jpeg` / `.webp` / `.gif`，不接受远程 URL、目录外路径或 SVG。放大展示读取同一张图片，不额外生成高清图。替换图片后“刷新库”并重新点选即可；建议同时增加版本号。

## 兼容原有 subject + tags

已有库无需为了新版节点重新拆词。未提供 `text` 或 `text` 为 `null` 时，使用：

```json
{
  "schema": 1,
  "family": "daily/garden",
  "label": "日常 · 庭院",
  "entries": [
    {
      "id": "garden_002",
      "title": "树下读书",
      "subject": "one adult person, solo",
      "tags": "reading a book, garden, soft afternoon light",
      "nl": null,
      "undress": "clothed",
      "intensity": 1,
      "scene": "garden",
      "camera": "eye-level",
      "focal": 50,
      "negative": "",
      "seed": 123,
      "preview": "garden_002.webp",
      "ver": 1
    }
  ]
}
```

输出恰好是 `subject + ", " + tags`。`subject` 必须为非空字符串，`tags` 必须为字符串。二者不会被翻译、清洗或重排。

`text` 存在且为字符串时优先，包括有意留空的 `text: ""`。`nl` 可保留供素材维护使用，也参与关键词搜索；本版不把它自动切换为另一路输出。若要输出自然语言，把所需完整原文放入 `text`，或配置另一份自然语言数据源。`negative`、`seed` 可以保留，但不参与正文拼接。

不执行早期稿件中的禁词 / 外观词检查；用户自行手改。ID 重复时保留同源先加载的条目并显示提示。非法文件和条目局部跳过；源目录缺失会显示数据源不可用。

## 多个 JSON 数据源

把以下内容放入插件根目录 `config.json`，替换为本机绝对路径：

```json
{
  "aaalice_db": "",
  "neons_sources": [],
  "json_sources": [
    {
      "id": "my_characters",
      "label": "我的角色库",
      "kind": "character",
      "directory": "D:/my-library/characters",
      "preview_directory": "D:/my-library/previews"
    },
    {
      "id": "my_outfits",
      "label": "我的服饰库",
      "kind": "outfit",
      "directory": "D:/my-library/outfits",
      "preview_directory": "D:/my-library/previews"
    },
    {
      "id": "my_content",
      "label": "我的内容库",
      "kind": "content",
      "directory": "D:/my-library/content",
      "preview_directory": "D:/my-library/previews"
    }
  ]
}
```

`kind` 决定进入哪个页签，默认 `content`。同类可配置多个来源。省略 `preview_directory` 时，使用该数据目录下的 `previews` 子目录。

数据源 ID 使用 `[a-zA-Z0-9_-]+`，全局唯一。条目的内部标识是 `source_id:entry_id`，不同来源可有相同 entry ID。

## Aaalice

省略 `aaalice_db` 时，默认从 ComfyUI 当前 user 目录定位数据库。使用便携版或自定义 user 目录时，可设置数据库绝对路径。空字符串代表不接入。

```json
{
  "aaalice_db": "D:/ComfyUI/user/aaalice/prompt-library/prompt-library.sqlite3",
  "aaalice_categories": {"角色": "character", "服饰": "outfit"}
}
```

读取顶层分类及其全部子分类，图片从数据库相邻 `assets` 目录读取。SQLite 以只读连接打开，不改变原有库结构。不会把“画风”类自动搬到正文。

## Neons

必须按实际库名填写 family 映射，不能仅凭 Anima、MOSS 等名字推断它是角色库。

```json
{
  "neons_sources": [
    {
      "id": "neons",
      "label": "Neons 中的角色与服饰",
      "file": "D:/NeonsStyleExplorer/user/custom.json",
      "manifest": "D:/NeonsStyleExplorer/user/previews/manifest.json",
      "preview_directory": "D:/NeonsStyleExplorer/user/previews",
      "text_field": "tags",
      "families": {
        "实际角色族名称": "character",
        "实际服饰族名称": "outfit"
      }
    }
  ]
}
```

`text_field: "tags"` 将源库 tags 字符串数组用逗号空格连接；`text_field: "nl"` 使用源库 nl 原文。预览清单按 Neons 的处理后 ID 查找 `cover` 文件名。没有预览清单可省略 `manifest`，文字仍可使用。

所有配置片段需要合并到同一个 JSON 对象，不能把多段 JSON 直接首尾相接。不要把个人 `config.json`、图片、数据库或个人素材提交到公开仓库。
